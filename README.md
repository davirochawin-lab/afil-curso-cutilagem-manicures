## Deploy na Netlify
1. Envie todos os arquivos desta pasta para um repositório no GitHub (o `index.html` deve ficar na raiz).
2. Na Netlify: "Add new site" > "Import from Git" > escolha o repositório.
3. Build command: deixe vazio. Publish directory: `.`
4. Ou arraste esta pasta direto em https://app.netlify.com/drop
